## チェックリスト

### グリッド整合性
- [ ] 12カラムグリッド (`repeat(12, 1fr)`) に沿っているか
- [ ] テキスト要素はカラムの左端に揃えているか
- [ ] 右カラムの画像は右端 (`margin-left: auto`) に揃えているか
- [ ] 全グリッドセルに `min-width: 0` があるか
- [ ] grid-column の中央配置は `4 / span 6` を使っているか

### モバイル対応
- [ ] `@media (max-width: 900px)` でのレイアウト崩れがないか
- [ ] 新しいグリッドCSSクラスにモバイルオーバーライドがあるか
- [ ] 1カラムフォールバック (`grid-column: 1 / -1`) が設定されているか

### CSS品質
- [ ] `!important` を使っていないか
- [ ] ハードコード値ではなく CSS カスタムプロパティを使っているか
- [ ] インラインスタイルでレイアウト指定していないか
- [ ] 同名・類似のCSSクラスが既に存在しないか確認したか
- [ ] `@media` ブロックはファイル末尾に配置されているか

### テーマ・カラー
- [ ] ライト/ダーク両テーマで表示を確認したか
- [ ] 色指定に CSS 変数 (`--fg`, `--bg`, `--muted` 等) を使っているか

### スペーシング
- [ ] 垂直余白が他ページと同じ値か
- [ ] `clamp()` ベースの `--space-*` 変数を使っているか
- [ ] ページ固有の余白条件分岐 (`:has()`, `:not()`) を追加していないか

### アクセシビリティ
- [ ] `focus-visible` スタイルがあるか
- [ ] `prefers-reduced-motion` を考慮しているか
- [ ] 画像に適切な alt テキストがあるか
